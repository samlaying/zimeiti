## 二、超级爆款文章的五大共性

### 共性一：选题覆盖数以亿计的潜在读者

**核心原则**：选题覆盖的人群基数要足够大。

- **底层逻辑**：选题铺的面越广 → 潜在阅读人数越多 → 爆发天花板越高
- **反面法则**：小众选题永远做不了大爆款，没有例外，没有意外

**案例拆解**：

| 选题 | 潜在受众规模 | 分析 |
|------|-------------|------|
| 共享单车相关（2篇） | 数以亿计 | 2016下半年~2017上半年最火话题之一，几乎全民参与 |
| 985毕业生的大学简史 | 数千万~上亿 | 所有大学生 + 毕业没几年的职场人群，基数巨大 |
| 九年后震后余生 | 全国人 | 汶川地震牵动每一个中国人的心弦，九寨沟地震二次引爆关注 |

**差异化角度的启示**：
- 九寨沟地震时，所有人正面竞争写九寨沟 → 新世相偏偏借势写**汶川地震**幸存者故事 → 天时地利人和，短时间突破700万
- **做爆款时要有差异化思维**，避免和所有人正面竞争

**实操建议**：
> 如果你想做爆款选题，但一想这个选题有点小众，就可以果断放弃。同时有多个选题可做时，优先选择覆盖面更大的那个。

---

### 共性二：话题暗藏巨大的社交属性

**核心原则**：新媒体 = 社交媒体，不社交，无媒体。

**社交属性的本质**：内容可以辅助用户的社交行为——

| 社交功能 | 说明 |
|----------|------|
| **帮用户表达** | 用户想说但说不出的话，你替他说了 |
| **让用户分享** | 内容成为用户的"社交货币" |
| **供用户讨论** | 话题天然适合在人群中引发讨论 |

**用户发朋友圈的真实心理**：
- 越来越谨慎
- 发的不是"我想发的"，而是"我想让朋友看到的"
- 展示的不是真实的自己，而是想塑造的那个自己
- 分享的不仅是有用的，而是觉得"大家会感兴趣的"

→ 内容充当**社交货币**，承担社交功能

**案例拆解**：

| 文章 | 社交属性表现 |
|------|-------------|
| 逃离北上广（新世相） | "逃离北上广"本身社交属性极强，办公室、朋友圈、饭桌上都在讨论，一火起来摁都摁不住 |
| 丢书大作战（新世相） | "现代人的读书焦虑"同样是强社交话题，推出即刷爆朋友圈 |
| 别想不开去创业公司 | 账号主人群为职场人，"要不要去创业公司"天然就是讨论热点 |
| 吴京老婆相关文章 | 女性用户的社交话题，看完转发欲望很高 |

**实操建议**：
> 不管做什么内容，都要想办法注入社交属性，让文章成为用户社交行为的辅助工具。多设置容易在用户之间形成讨论的话题。什么样的话题容易被广泛讨论，没有统一标准，取决于你的主要用户群体。

### 共性三：内容饱含强烈的情感共鸣

**核心原则**：传播的最高级 = 引发共鸣。共鸣越强烈，转发欲望越强烈。

**底层心理**：
- 用户不是想看"你怎么表达"，而是看"你怎么**替他**表达"
- 用户想在你的文章中看到**他自己**
- 转发不是给你帮忙充KPI，而是借用你的文章完成**展示自我、表达自我、塑造形象**的目的

**爆款共鸣文的最大特点**：每一句话都让用户觉得"说到我心坎里去了"

**经典案例——《别想不开去创业公司》中的句子**：

> - "不能all in的不要来创业公司"
> - "平时和周末是没有差别的，上班和下班是没有界限的"
> - "别人周日晚在电视前看综艺节目，你在电脑前和客户焦头烂额，都要习惯"
> - "你要告别文艺小资的生活，比如一下午的美好时光，只负责慵懒"
> - "告别任性的来一段说走就走的旅行，诗和远方"
> - "在创业公司，工作就是生活，要不然你干嘛来创业公司啊？"

→ **每一句都想单独分享到朋友圈**

**共鸣的层次**：

| 层次 | 表现 |
|------|------|
| 题目级共鸣 | 光看标题就产生共鸣，不看内容就想转发 |
| 句子级共鸣 | 每一句话都触动心弦，恨不得每句都发朋友圈 |
| 结尾级共鸣 | 结尾一句话直击灵魂（如"晚安，北京，每次都想拥抱你，可我一无所有"） |

**更多标题级共鸣案例**：
- "今天你对我爱答不理，明天我让你高攀不起"
- "不要在该约炮的年纪谈修行"
- "赵雷，你终于红了！"

**实操建议**：
> 做内容一定要**避免自嗨**，不要只顾自我表达。要多从用户角度出发，替用户表达、替用户说话。你帮用户表达，用户才会帮你转发——你和用户之间是互相成就的。

### 共性四：新鲜形式带来新鲜感受

**核心原则**：人性猎奇，喜新厌旧。内容同质化越严重，用户越需要新鲜感。

**四类创新维度**：

| 维度 | 案例 |
|------|------|
| **玩法/包装创新** | 逃离北上广：话题老（讨论多年），但"说走就走+机票免费+酒店补贴+限定时间"让老话题焕发新生命力 |
| **观点创新** | 不要在该约炮的年纪谈修行：当大家追热点说"岁月静好"时，反其道说"年轻人应朝气蓬勃"，让人耳目一新 |
| **表达方式创新** | 同上文章：用段子式金句"不要在该约炮的年纪谈修行"表达"什么年纪干什么事"的旧观点，极接地气 |
| **呈现形式创新** | 共享单车照妖镜：几乎没文字，全程大量图片，用各种场景/角度/姿势的照片展示用户行为，不用说教，一看就懂 |

**更多创新启发**：

| 场景 | 创新方式 |
|------|----------|
| 大家都在转发"赵雷你终于红了" | 另一账号做"喜欢赵雷成都的人，你可能粉了一个假成都" → 同样火爆 |
| 同道大叔用图文漫画谈星座（审美疲劳） | 陈茂源用真人短视频脱口秀说星座 → 爆红 |
| 大家都在写九寨沟地震 | 新世相写汶川地震幸存者 → 阅读量700万+ |

**实操建议**：
> - 观点上要有新意，避免与所有人同质
> - 内容呈现上要更丰富（图文、视频、图片、互动等多种形式）
> - 追热点的姿势要做出差异化

### 共性五：标题让用户一眼看懂

**核心现象**：虽然公众号标题趋势变长（亮点堆积），但超级爆款的标题普遍**很短**。

**数据验证**：
- 10篇超级爆款中，**9篇**标题在20字以内
- 唯一超20字的（逃离北上广）也没超过25字
- 阅读量最高的"赵雷，你终于红了" → 也是10篇中标题**最短**的

**本质不是"短"，而是"一眼看懂"**：

| 原则 | 说明 |
|------|------|
| 简单 | 用常见常用词汇 |
| 直接 | 不绕弯子，不复杂 |
| 明了 | 一眼就能理解意思 |
| 抓人 | 虽然简单但有情绪张力 |

**正面案例**：

| 标题 | 字数 | 效果 |
|------|------|------|
| 别想不开去创业公司 | 11字 | 简单精炼好懂，充满共鸣 |
| 今天你对我爱答不理，明天我让你高攀不起 | 对比句 | 一眼看懂，看完就想转发 |
| 他们在等待道歉，日本政府在等待他们死去 | 短句对比 | 一眼明了，激发情绪 |
| 吴京，你终于火了！ | 短 | 继续"赵雷你终于红了"的成功模式 |

**反面案例（战狼2时期）**：

| 标题 | 结果 | 原因 |
|------|------|------|
| 因为遇到了吴京，中美混血的她，从丑小鸭变成了战狼二里最美的女人 | 未突破10万+ | 又长又复杂，不符合一眼看懂原则 |
| 这个中美混血怎样练成战狼二最美的女人？ | 突破10万+ | 更短更直接，一眼看懂 |

**实操建议**：
> 用户刷朋友圈速度很快，标题扔在朋友圈里必须让人**一眼看懂**。不管用什么技巧，最后一定要满足"一眼看懂"这个标准。越想做超级爆款，越要让所有人都能秒懂。

## 三、综合案例串联——以《摩拜CEO：失败了就当做公益吧》为例

用五大共性逐一验证：

| 共性 | 具体表现 |
|------|----------|
| **① 选题覆盖广** | 摩拜单车注册用户超1亿，潜在读者基数巨大，引爆前提充分 |
| **② 社交属性强** | 共享单车是当时最火爆话题之一，朋友、同事之间经常讨论 |
| **③ 情感共鸣深** | 三个高共鸣场景：创始人创业艰难的段落 / 国民素质差毁坏单车的场景 / 凌晨两点保洁阿姨骑摩拜回家的场景 |
| **④ 形式有新鲜感** | ①摩拜创始人首次公开演讲（少见+视频形式）②观点新鲜："创业失败就当做公益"说法新颖 |
| **⑤ 标题一眼看懂** | 标题简短精炼，常见词汇，一眼明了 |

> **一般来说，超级爆款都会同时满足这五点。** 今后遇到刷屏级爆款，可以尝试用这五点去分析拆解。

## 四、课程总结与延伸思考

### 关于爆款意识

> **爆款 = 流量 = 一切生意的本质**

- 无论变现模式是广告还是电商，都需要流量支持

### 关于流量品质

> 要**有选择地**要流量，而非不择手段地追求流量

| 高价值流量 | 低价值流量（需避免） |
|-----------|-------------------|
| 符合账号定位的流量 | 标题党骗来的流量 |
| 有品牌感的流量 | 强蹭热点蹭来的流量 |
| 高转化价值的流量 | 诱导分享得来的流量 |
| | 三俗话题博眼球的流量 |

> 低价值流量不仅不值钱，还会一步步**摧毁你的品牌**。

### 总结框架图

```
超级爆款文章五大共性
│
├── 1. 选题：覆盖数以亿计的潜在读者（基础门槛）
│
├── 2. 社交：话题暗藏巨大社交属性（传播引擎）
│
├── 3. 共鸣：内容饱含强烈情感共鸣（转发动力）
│
├── 4. 新鲜：形式/观点/表达带来新鲜感受（打破同质化）
│
└── 5. 标题：让用户一眼看懂（朋友圈第一道关卡）
```
