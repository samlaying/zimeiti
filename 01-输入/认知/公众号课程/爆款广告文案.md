# 爆款广告文案 · 电商文案写作方法

> 课程来源：十点课堂 · 周佐罗（系列课最后一节）
> 核心主题：公众号销售文案的写作方法，直接关系转化率与用户体验

---

## 核心观点

- 同一商品，好文案与差文案的转化率可能相差**数倍**
- 公众号广告的核心特征：**要求即时转化**（发出去后马上收到订单）
- 例：十点读书二条广告位10万元，课程售价99元 → 至少卖出**1000份**才能回本
- 销售文案是**系统工程**，每一环都至关重要

---

## 案例背景

**推广课程：**「微信公众号运营90招速成指南」（与插座学院合作）

- 售价：**298元**
- 付费人数：突破**26,000人**
- 成绩：全网公众号类课程**第一名**
- 文案标题：《从月薪5000公众号小编逆袭成年薪50万副总裁，他只用了18个月》

---

## 一、选题立意（决定成败的关键节点）

### 核心原则

> "不要用战术上的勤奋掩盖战略上的懒惰"

- 先解决**决定成败的关键问题**——说服用户的逻辑是什么
- 选题立意 = 你说服用户的核心逻辑

### 操作要点

- 能先写出一个很牛的题目 → 说明说服逻辑已经打通 → 选题立意自然成型
- **选题立意与想标题往往是同时进行的**

### 案例拆解

该文案的说服逻辑链条：

```
起点很低的普通人（无媒体背景、毕业不到三年）
        ↓
零基础入行新媒体，从月薪5000做到年薪50万（仅18个月）
        ↓
证明新媒体行业：成功可能性大 + 入行门槛低
        ↓
不需要相关背景、不需要太多资源
        ↓
结论：普通人实现职业逆袭的最好机会
        ↓
他做到了 → 你也有机会 → 购买课程即可学习
```

逻辑**行得通**、说服力**足够强** → 转化效果自然好

## 二、文案标题

### 通用标题套路（前序课程已讲）

| 套路 | 说明 |
|------|------|
| 激发好奇 | 让用户想知道答案 |
| 引发共鸣 | 让用户觉得"说的就是我" |
| 戳中痛点 | 让用户感受到焦虑/需求 |
| 制造预期 | 让用户预知阅读的收获 |
| 蹭知名度 | 借助名人/名品牌/名平台背书 |

### 销售文案标题的特殊要求

#### 技巧一：标题与商品要有相关性 → 保障流量精准性

- 标题中最好带有**商品标签**，向潜在买主打招呼
- 卖公众号课程 → 标题中提及「公众号」「新媒体」「十万加」等字眼
- 这类用户看到标题基本都会点开

**关键区分：**

| 追求指标 | 广告电商文案 | 普通文章 |
|---------|------------|---------|
| 核心目标 | **高转化率** | 高阅读量 |
| 流量质量 | 精准潜在客户 | 尽可能多的曝光 |

> "宁可要5,000个精准潜在顾客点开，也不要20,000个非精准用户点开"

**规律：**
- 商品**越贵、越小众** → 越需要精准流量
- 商品**越便宜、越大众** → 可适当放开，但也不能完全不相干

#### 技巧二：标题要展示阅读预期和利益回报

- 相比激发好奇和引发共鸣，**更重要的是让每个人看到利益回报**
- 因为最终目的是让用户**掏钱购买**

**案例标题分析：**

| 标题 | 用户心理反应 |
|------|------------|
| 从月薪5000公众号小编逆袭成年薪50万副总裁，他只用了18个月 | "这个同行太牛了，我要学习" / "做公众号这么赚钱，我也有机会" |
| 全网第一公众号爆款课，讲师两天全程干货，教你成为最值钱的新媒体人才 | "我学的是全网最好的课 → 听完就更值钱 → 有助升职加薪 → 只需两天" |

> **奥格威名言：** 读标题的人数平均为读正文人数的**5倍**。标题代表着一则广告**80%**的价值。

## 三、文案开头

### 总体要求

- 开头要**吸引用户继续往下看**，而非点开就关闭
- 广告电商文案的特殊要求：**直接带动销量**

### 两大常用技巧

#### 技巧一：制造向往

**本质：** 描述一个人人都想成为的样子、想过上的生活、想达成的目标

**洗发水案例：** 飘柔广告 → 展示一头人人向往的秀发 → 告诉你她用的是飘柔

**课程文案案例：**
- 开头提出疑问：「新媒体编辑月薪五万，真的很难吗？」
- 接着讲作者经历：毕业不到三年拿到50万年薪 + 成为爆款课讲师 + 世界500强企业讲师
- **虽然现在很牛，但起点比很多人都低**

→ 给所有公众号从业者制造向往 → 想知道怎么做到 → 继续往下看

#### 技巧二：戳中痛点

**洗发水案例：** 海飞丝 → 一上来讲头皮屑多让人烦恼、多让人尴尬 → 戳中痛点 → 再推出产品解决方案

**课程文案案例：**
- 开头先讲年轻职场人的普遍痛点：

> "每天朝九晚六在格子间做着重复的工作，拿着固定的工资，望着一眼就看得到头的未来，你是否想要逃离却无能为力？"

→ 读者被戳中（扎心了） → 引出作者的故事 → "或许这个北漂青年的故事可以帮你的人生打开新的可能"

## 四、主体故事

### 淘宝 vs 公众号消费的本质区别

| 维度 | 淘宝购物 | 公众号购物 |
|------|---------|-----------|
| 消费动机 | **先有需求** → 搜索 → 对比 → 购买 | **随机行为** → 刷朋友圈 → 看文章 → 被打动 → 购买 |
| 决策依据 | 参数、功能、性价比 | **故事、生活方式、价值观** |
| 消费逻辑 | 理性比较 | **情感驱动** |

### 核心原则：讲故事，而非讲道理

- 不要一味讲道理、讲理论、讲功能、讲参数
- 这些可以讲，但要**附着在故事里**
- **没有人不喜欢看故事**——大脑就是被设计成这样的

> 两个课程文案的主体内容都是：作者通过公众号实现逆袭的励志故事
>
> 用户在消费故事的过程中 → 产生学习的激情、成功的渴望、逆袭的向往、改变的决心 → 推荐的东西又正好与自身情况相符 → 自然下单

### 故事写作两大技巧

#### 技巧一：注重细节描述 → 增加真实性与共鸣感

- 不讲细节 → 故事沦为材料的堆积
- 讲细节 → 故事更真实、更丰满、更有代入感

**案例中的细节运用：**

| 故事阶段 | 细节运用 |
|---------|---------|
| 北漂经历 | 住地下室、摆地摊、做服务员 → 让北漂故事更有说服力和共鸣 |
| 转型做小编到爆文写手 | 还原做出第一篇百万加爆文的过程、心情、思考 + **当时的朋友圈截图**辅助 |
| 进一步逆袭 | 从零打造新账号的真实经历：什么时间注册、什么时间发第一篇、效果如何、什么时间做出第一篇十万加… |

#### 技巧二：故事逻辑性强 → 步步引发用户疑问

**核心套路：** 不断让用户产生疑问 → 设疑 → 回答 → 再设疑 → 再回答 → 用户被好奇心牵引着一路读到底

**案例中的逻辑链条：**

```
疑问①：新媒体编辑月薪五万真的很难吗？
    ↓ 回答
不难，我毕业不到三年就做到了
    ↓ 产生新疑问②：你是怎么做到的？
    ↓ 回答
讲我的逆袭经历——最初摆地摊、做服务员，后来遇到转折入行新媒体
    ↓ 产生新疑问③：发生了什么转折？入行后怎么样了？
    ↓ 回答
讲入行后的经历……（循环推进）
    ↓
好奇心一路牵引 → 直到看完全部广告文案
```

## 五、商品展示

主体故事讲完后，引出要卖的商品。展示结构如下：

### 展示框架

```
商品海报 → 商品简介 → 商品亮点 → 利益回报
```

### 1. 商品海报

- 讲完故事后**马上**引出产品
- 两个要求：
  - ① 让用户**一眼明了**商品是什么
  - ② 海报设计要**抓眼球**，让用户一下被吸引

**案例：**
- 颜色有辨识度的课程海报
- 左侧：个人形象照
- 右侧：有辨识度的课程名字 + 「用公众号增加收入，掌握最热门的职场技能」

### 2. 商品简介

- 海报之后，用户会关心具体信息，需稍加介绍
- **重点要素：**
  - 视频课程介绍
  - **课程大纲展示**（最重要）

> 知识付费时代，用户买课时主要看课程表 → 如果感觉「好有用、好系统、好全面」→ 直接刺激下单

### 3. 商品亮点

- 篇幅不用太多，但要罗列**最大的亮点和价值点**
- 本质：想尽办法让大家觉得「买这个太值了」

**案例——课程五大价值点：**

| 序号 | 亮点 |
|------|------|
| 1 | 公众号学习一站式解决方案 |
| 2 | 帮你建立完整的新媒体知识体系 |
| 3 | 注重实战，学一招会一招 |
| 4 | 超高性价比：90节课 |
| 5 | 音频+PPT听课，购买后可反复听12个月 |

### 4. 利益回报

- **不管前面说了多少次，最后部分必须再重说一遍**
- 这是让用户付款的**最后关键刺激**

**案例——明确的课程回报：**

```
四大学习模块，助你从零基础到大神

├─ 零基础小白 → 学完前两个模块
│   → 找到公众号相关工作 或 兼职撰写文案赚取收益
│
├─ 有基础从业者 → 学完后两个模块
│   → 成为新媒体稀缺人才，争取更好薪资
│
├─ 愿意折腾的人 → 注册自己的公众号
│   → 打造个人品牌，走上创业之路
│
└─ 学完全部课程 → 获得插座学院优秀学员证书
```

## 总结：广告电商文案五步写作框架

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│  ① 选题立意 —— 确定说服用户的核心逻辑               │
│       ↓                                             │
│  ② 文案标题 —— 高转化 > 高点击                      │
│     · 标题与商品相关（精准流量）                     │
│     · 展示购买利益回报                               │
│       ↓                                             │
│  ③ 文案开头 —— 二选一策略                           │
│     · 制造向往（你也能成为这样的人）                 │
│     · 戳中痛点（你的问题我可以解决）                 │
│       ↓                                             │
│  ④ 主体故事 —— 情感驱动消费                         │
│     · 注重细节 → 真实感、代入感                      │
│     · 逻辑严密 → 步步设疑、牵引阅读                  │
│       ↓                                             │
│  ⑤ 商品展示 —— 促成最终购买                         │
│     · 海报（一眼明了 + 抓眼球）                      │
│     · 简介（课程大纲为核心）                         │
│     · 亮点（最大价值点罗列）                         │
│     · 利益回报（最后的付款刺激）                     │
│                                                     │
└─────────────────────────────────────────────────────┘
```
