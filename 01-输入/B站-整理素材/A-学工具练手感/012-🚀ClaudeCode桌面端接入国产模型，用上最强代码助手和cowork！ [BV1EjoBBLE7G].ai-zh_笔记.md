# 012-🚀ClaudeCode桌面端接入国产模型，用上最强代码助手和cowork！

> 摘要：教程演示如何在 Claude Code 桌面端客户端中配置并接入 MiniMax 等国产大模型，实现 Cowork 和 Code 模式的本地化使用。

> ⚠️ 外部参考：这是收藏的视频内容，不代表本人经历、成果或能力证据。

## 关键要点
- 介绍 Claude Code 客户端支持接入第三方模型，可替代或增强官方服务。
- 详细步骤包括下载安装包、开启开发者模式（Help > Trouble Shot）、配置第三方模型及重启。
- 配置核心涉及获取国产模型（如 MiniMax）的 API Key 和 Gateway URL。
- 需在客户端设置中填入模型名称（如 m2.7）并开启长上下文支持。
- 通过开启“跳过登录模式”解决部分网络或账号限制问题。
- 最终通过 Cowork 对话模式和 Code 文件夹模式测试连接是否成功。
