# 7分钟速通Agent Skills是什么？跟MCP｜Workflow｜Command｜Prompt有什么关系？

> 摘要：解析AI Agent中Skill的概念及其与MCP、Workflow、Command和Prompt的关系，阐述如何通过模块化文件管理实现动态加载与逻辑编排。

> ⚠️ 外部参考：这是收藏的视频内容，不代表本人经历、成果或能力证据。

## 关键要点
- 基础概念：从User Prompt到System Prompt，再到通过Command快捷调用固定文本，提升指令遵循度。
- 元数据机制：利用Metadata（简短描述）让模型快速识别场景，按需加载完整Prompt文件，大幅节省Token成本。
- 渐进式披露：通过References（参考文档）和Scripts（执行脚本）文件夹，实现按需读取文件和运行代码，避免一次性输入所有上下文。
- Skill定义：将System Prompt、References和Scripts打包为文件夹结构，形成可复用的‘技能’模块。
- Skill vs MCP：MCP提供工具（手），Skill提供操作经验和流程（脑+手），解决工具组合使用的逻辑问题。
- Skill vs Workflow：Workflow是设计时固定的规则流程，Skill是运行时由LLM驱动的灵活编排，本质是‘LLM驱动的Workflow’。
