# Agent Skills：PPT 制作全流程实战指南

> [云上天探索Ai](https://space.bilibili.com/417321617) | [BV1bs6MBzE6g](https://www.bilibili.com/video/BV1bs6MBzE6g) | 时长 8:29

## Agent Skills 概述
### 什么是 Agent Skills
Agent Skills 是一种将复杂提示词模块化、封装成可复用技能的标准，旨在将 AI 从通用助手转变为各领域专家。它允许用户编写一次技能，在不同项目或场景中直接复用，避免重复编写冗长的提示词。Skills 是一个开放标准，不绑定任何平台，支持多种 AI 工具如 CloudCode、Cursor、Tree 等。

### Skills 的优势
- **模块化与复用**：将提示词封装成独立模块，提高效率，减少 Token 使用。
- **领域专家化**：通过特定技能定义，使 AI 在特定任务上表现更专业。
- **开放标准**：首次发布于 2025 年 10 月，2025 年 12 月 18 日正式开放，确保跨平台兼容性。
- **易于管理**：技能文件结构清晰，便于维护和扩展。

### Skills 标准发布时间
- 首次发布：2025 年 10 月
- 正式开放：2025 年 12 月 18 日

## PPT 制作 Skills 实操指南
### 环境准备
- 使用工具：VSCode（编辑器）和 CloudCode（AI 调用工具）
- 项目命名：例如“创建PPT”，可自定义

### 创建项目结构
1. 在 VSCode 中创建新项目，命名为“创建PPT”。
2. 在项目根目录下创建 `.cloudcode` 目录，用于存放 CloudCode 相关文件。
3. 在 `.cloudcode` 下创建 `skills` 文件夹，用于存放多个技能任务。
4. 在 `skills` 文件夹下创建子文件夹，每个任务对应一个技能，例如：
   - `PPT-生成`：用于 AI 生成 PPT
   - `PPT-移动`：用于文件移动（示例任务）
5. 在每个技能文件夹下创建 `Skills.md` 文件，用于编写提示词和元数据。

### 编写 Skills 文件
- **Skills.md 文件格式**：
  - 使用三个短横线 `---` 包裹元数据。
  - 包含 `LAM`（技能名称）和 `描述` 字段。
  - 示例内容：
    ```
    ---
    LAM: AI生成PPT
    描述: 你是一个专业的PPT生成工具，内置了什么引擎，不要生成什么样的PPT。使用方法：读取API密钥，位于script/.env文件中。
    ---
    ```
  - 建议：描述越详细，AI 执行越准确。

### 创建脚本和配置文件
1. 在技能文件夹下创建 `script` 子文件夹，用于存放脚本和配置。
2. 创建 `.env` 文件，存储 API 密钥等配置信息。
3. 创建 Python 脚本（如 `mr.py`），用于执行 PPT 生成逻辑（字幕中未给出完整代码，但强调是 Python 文件）。
4. 创建 `requirements.txt` 文件，列出脚本依赖的库文件，便于安装。

### 调用 CloudCode 运行 Skills
1. 保存所有文件。
2. 在 VSCode 中打开终端，导航到项目根目录。
3. 启动 CloudCode 命令：输入 `cloudcode --scale` 来检测和加载技能。
4. CloudCode 会自动识别 `skills` 文件夹下的技能，例如“AI生成PPT”和“文件移动”。
5. 当用户输入指令（如“帮我生成PPT”），AI 会匹配对应技能并执行。

## Skills 使用演示
### 生成 PPT 实例
- 用户指令：“帮我做一个年中总结PPT”
- AI 自动检测到“AI生成PPT”技能，并确认使用。
- 执行过程：
  - 检查目标结构和配置文件。
  - 调用 Python 脚本生成 PPT。
  - 如果缺少 API 密钥，AI 会从 `.env` 文件中提取并补全命令。
- 结果：PPT 被生成并保存到指定目录（如“地盘PPT目录”），但未生成图片，因为 API 余额不足；AI 会说明原因并建议手动添加图片。

### 错误处理示例
- 当 API 余额不足时，AI 会智能识别问题，生成排版和文字内容，但跳过图片生成，并提示用户原因。
- 这体现了 Skills 的实用性：AI 能基于技能描述处理异常情况。

## Skills 与 MCP 的区别
- **Skills**：本质是提示词模块化封装，以 Markdown 文档形式存在，专注于任务定义和复用。
- **MCP（Model Context Protocol）**：需要编写服务端接口，由 AI 调用接口执行任务，侧重于服务集成。
- **关系**：两者互补，无直接冲突。Skills 用于定义“做什么”，MCP 用于实现“怎么做”，可结合使用提升 AI 能力。

## 总结
Agent Skills 通过将提示词模块化、标准化，实现了 AI 技能的跨平台复用，显著提高了工作效率，特别适合复杂任务如 PPT 制作。实操中，用户只需在 VSCode 中创建结构清晰的技能文件（包括元数据、脚本和配置），通过 CloudCode 调用即可让 AI 自动执行任务。Skills 与 MCP 互补，共同扩展了 AI 的应用范围，使 AI 更专业化、智能化。核心优势在于开放性、易用性和可扩展性，帮助用户从繁琐的提示词管理中解放出来。
