# Claude Code 实战配置集合，Everything Claude Code ，提升效率，规范ai编程！

> [三少科技](https://space.bilibili.com/484719715) | [BV1wEzvBvE2f](https://www.bilibili.com/video/BV1wEzvBvE2f) | 时长 4:27

## 项目概述
### 项目背景
- 项目名称：**Everything Claude Code**，一个完整的 Claude Code 配置集合，旨在提升 AI 编程效率并规范开发流程。
- 开源项目，由 UP 主三少科技介绍，目前已收获 28.4K star，尽管项目仅剩一周时间，但非常受欢迎。
- 作者背景：2025 年 9 月，作者用 Claude Code 参加 Anthropic 举办的 Paykerson 比赛并获得冠军，整个项目（包括获胜作品）完全用 Claude Code 开发，积累了超过 10 个月的实战配置并开源。
- 项目价值：不是 demo，而是经过真实生产环境验证的配置集合，对 Claude Code 用户有重要参考意义。

### 项目内容概览
- 配置集合包括以下核心组件：
  - **Agents（子代理）**
  - **Skills（技能库）**
  - **Commands（斜杠命令）**
  - **Hooks（自动化钩子）**
  - **Rules（规则）**
  - **MCP 配置**
- 项目文档包含两份指南：简明指南（基础配置和使用方法）和长篇指南（高级主题如 token 优化、记忆持久化、并行化策略等），这些指南比代码本身更有价值，是实战经验的总结。

## 详细配置内容
### 子代理（Agents）
- 项目包含 9 个专业子代理，每个代理负责不同任务，可理解为虚拟技术团队：
  - **Planner**：功能规划，将大任务拆解成小步骤。
  - 系统架构设计代理。
  - **Code Review** 代理。
  - **TDD（测试驱动开发）** 代理。
  - 安全质量审查代理。
  - 漏洞分析代理。
  - 构建错误修复代理。
  - **Playwright E2E 测试** 代理。
  - 死代码清理代理。
  - 文件同步代理等。

### 技能库（Skills）
- 提供可复用的工作模板，避免每次从零开发：
  - 前端开发：使用 **Legget, Negget, JS** 等获得最佳实践。
  - 后端 API 设计模式。
  - 数据库和缓存处理方式。
  - **TDD 测试驱动开发** 完整流程。

### 斜杠命令（Commands）
- 提供 10 个常用斜杠命令，一键触发复杂工作流程：
  - 例如：测试驱动开发、实现规划等命令。
  - 方便用户快速启动常见开发任务。

### 自动化钩子（Hooks）
- 在特定时机自动触发，实现开发环境自动化：
  - 编辑 TypeScript 文件时，自动运行类型检查。
  - 写代码后，自动用 **Plator**（可能指 Prettier 等格式化工具）格式化代码。
  - 检测到 **console.logger** 时，自动提醒删除。
  - 会话开始前，自动添加上次的上下文。
  - 作用：像智能管扎，自动处理琐事，提升开发效率。

### 规则（Rules）
- 定义开发规范，Claude Code 在写代码时会自动遵守：
  - 安全检查规则。
  - 代码风格规范。
  - 测试覆盖率要求。
  - Git 提交格式等。

### MCP 配置
- 配置常用服务，使 Claude Code 可以直接操作这些服务：
  - **GitHub** 操作。
  - **Supabase** 数据库操作。
  - **Vercel** 部署。
  - **Cloudflare Workers** 等。

## 使用建议与技巧
### 上下文窗口管理
- **关键数据**：Claude Code 的 200K 上下文窗口可能因启用过多工具缩减到 70K。
- **建议**：配置 20-30 个 MCP，但每个项目中只启用 10 个以内，以优化上下文使用。

### 定制化配置
- 配置基于作者的工作流程，不一定完全适合所有用户。
- **建议**：先从有用的部分开始，逐步添加，删除用不到的配置，以个性化定制。

### 阅读配置指南
- 项目提供两份详细指南：简明指南和长篇指南。
- **重要性**：指南比代码更有价值，涵盖基础配置、使用方法、token 优化、记忆持久化、并行化策略等高级主题，是实战经验的总结。
- **建议**：务必阅读这些指南以深入理解和使用项目。

## 实操步骤
- 使用方法相对简单，主要步骤包括：
  1. 运行命令添加仓库（具体命令需参考项目文档）。
  2. 运行命令安装插件。
- 安装后即可获得所有配置集合。
- **注意**：具体命令在字幕中未提供，建议查看项目文档获取完整步骤。

## 核心要点总结
该项目是一个基于真实生产环境验证的 Claude Code 配置集合，通过子代理、技能库、斜杠命令、自动化钩子和规则等组件，系统化提升了 AI 编程的效率和规范性。其最大价值在于背后的方法论，展示了如何组织 Claude Code 工作流、利用自动化工具和保证代码质量，即使不直接使用，研究这些配置也能学习到高手的实践技巧。用户应注意上下文窗口管理、个性化定制并阅读详细指南，以最大化项目收益。
