## Everything Claude Code：实战配置笔记

### 一、 背景与概述
- **来源**：这套系统由一位 **Anthropic编程马拉松冠军** 花费**十个月**的日常实战打磨而成，每个配置都经过真实项目考验。
- **目标**：将AI从“问答工具”升级为 **“为你量身打造的、能记忆、能自学的开发系统”**，彻底释放AI潜力。
- **系统核心思想**：简单、专注、自动化、并行。

### 二、 系统三大核心组件
这套系统的核心由以下三个部分组成，构成了强大AI工作流的“龙骨”：
1.  **技能 (Skills)**
    - **定义**：为AI准备好的“行动剧本”或“武功秘籍”，定义的是一个**宏观的、分步骤的复杂工作流程**（战役）。
    - **作用**：明确AI的行动范围和战略。例如，“重构整个登录模块”是一个技能。
    - **与“命令”区别**：技能管宏观战略，命令管具体战术（如“找到`user.js`文件”）。

2.  **钩子 (Hooks)**
    - **定义**：预先设置的自动化**触发机关**，在AI使用某个工具**之前或之后**自动启动。
    - **作用**：充当整个流程的**自动化安全网和加速器**。
    - **巧妙用法示例**：设置一个“工具使用后钩子”，在Claude每次完成任务后自动获取反馈或检查结果，实现**实时校准**，无需等到最后才发现错误。

3.  **子代理 (Subagents)**
    - **定义**：专注于特定任务的“外聘专家”，在后台独立工作。
    - **作用**：将复杂任务（如代码审查、系统规划）从主聊天窗口剥离，**保持主线程清爽**。
    - **优势**：可组建虚拟专家团队，按功能分工（如一个负责规划，一个负责测试，一个负责审查），**极大提升效率**。

### 三、 解决AI的“健忘症”：记忆与自我进化机制
- **核心问题**：AI默认“失忆”，每次新对话都忘记上下文，导致重复劳动和效率低下。
- **解决方案：持久化钩子与记忆闭环**
    1.  **记忆保存**：聊天结束时，一个钩子自动将**本次聊天的精华（关键知识点）** 保存到文件。
    2.  **记忆加载**：下次开始新对话时，另一个钩子自动将这些记忆**加载回来**。
    - 这样形成了一个完美的**记忆闭环**。
- **高阶能力：自我进化**
    - **机制**：系统不止记笔记，还能**主动学习**。它会自动分析聊天记录，识别成功的互动模式。
    - **发动机**：**停止钩子 (Stop Hook)**。每次会话结束后，它启动评估脚本复盘，将成功经验**打包成新的、可复用的技能**。
    - **效果**：AI助手在每次任务完成后都可能变得更强大，实现 **“悄悄进化”**。

### 四、 高阶玩法：效率翻倍与成本优化
1.  **模型分级使用（好钢用在刀刃上）**
    - **原则**：不同任务匹配不同能力的模型，避免用昂贵模型处理简单任务（如“开跑车去买菜”）。
    - **示例**：文件搜索等简单任务使用更经济的模型（如Hiku），成本与顶级模型（如Opus）有**天壤之别**，长期能节省大量费用。

2.  **并行工作流**
    - **方法**：使用如`Git WorkTree`等命令，**同时启动多个互不干扰的Claude实例**。
    - **效果**：如同拥有多个分身，每个分身在**独立、隔离的工作空间**（小房间）中并行任务，安全高效，速度提升不止一倍。

### 五、 实操建议与最终蓝图
- **配置哲学**：
    - **别搞复杂**：配置是为了微调，不是重新发明轮子。
    - **保持纯净**：关闭不用的插件，保持上下文清洁。
    - **追求并行**：尽可能并行处理任务，“速度就是生命”。
    - **彻底自动化**：将所有重复性、脏活累活交给钩子自动执行。
    - **聚焦子代理**：给子代理划好范围，确保它们**一次只专注一件事**。
- **最终蓝图**：一个由技能定义战略、钩子实现自动化与记忆、子代理负责专业细分任务、支持模型分级和并行执行的**自适应、自我进化的AI开发系统**。

### 核心要点总结
这套系统的核心在于将Claude Code从一个被动响应的工具，通过**技能（战略）、钩子（自动化与记忆）、子代理（专业化分工）** 三大支柱，构建成一个**具有长期记忆、能从经验中学习并自我优化、且能高效并行处理的智能开发伙伴**。它强调实战导向，通过模型分级使用和并行工作流实现**效率与成本的平衡**，最终目标是让AI深度融入开发流程，成为真正量身定制的“超级助手”。
