# 什么？Claude Code还可以十连抽PPT？

> [小天fotos](https://space.bilibili.com/28554995) | [BV1yqzsBrEnn](https://www.bilibili.com/video/BV1yqzsBrEnn) | 时长 7:34

## 核心理念：从“自我感动”到“优雅工作”
视频开篇指出传统PPT制作的两大痛点：**熬夜赶工**和**精心制作但观众不买账**，这往往是“自我感动”式的努力。2026年的解决方案是将重复劳动交给AI，将宝贵时间留给思考和创意。核心工具是 **Claude Code** 加上自定义的 **Skill**，目标是实现高效、优雅的PPT生成流程。

## 展示的优雅工作流程
UP主的工作流极具吸引力：
1.  **输入指令**：在Claude Code中输入 `/ppt generator`，并附上自己的讲稿，要求“请给我抽五次卡”。
2.  **自动处理**：AI会自动生成5份漂亮的演示文稿。
3.  **人类挑选**：UP主在此期间可以休息（晒太阳、煮咖啡），回来后从5份文稿中挑选每一页最好的，并让AI将它们合并。
4.  **实时预览**：另一块屏幕会实时刷新出修改后的效果。

这个过程被形容为“无比优雅，不费心思”，关键在于拥有一个**不限量的AI订阅套餐**和自定义的**Skill**。

## PPT Generator Skill 结构详解
UP主展示了其Skill目录的组成部分：
*   **入口脚本**：包含多个参数，这些参数由用户提出要求后，由AI自动调用脚本来生成初始模板（脚手架）。
*   **`Skill.md` 文件**：这是Skill的核心配置文件，结构严谨：
    *   **头部信息**：由`Skill Creator`生成。
    *   **风格定义**：明确了PPT的标题风格（如“乔布斯式”）、原则、类型模板（如对比式、比喻式）。
    *   **视觉规范**：规定了颜色、语义配色方案。
    *   **内容规则**：定义了讲稿的修正规则，要求使用**场景化**和**冲突式**的表达。
    *   **完整流程**：指定了从“读原稿”到“生成脚手架”、“修改PPT”的完整步骤。
    *   **代码规范**：指定了一个`PPT slide`的类（定义在`layout.js`中），这部分完全由AI（`Skill Creator`）自动完成。
*   **资源与模板**：`Templates`目录用于存放资源（如猫头图片，用于纪念UP主的猫）。

## 通用方法论：如何用Skill解决问题
UP主将案例升华为一个**不变的法则**，用于将任何问题流程化、工具化：
1.  **第一步（最关键）：用AI完整解决一次问题，制作模板**
    *   目标：做出一个漂亮、高质量的PPT作为后续生成的风格模板。
    *   **推荐工具**：
        *   **AI模型**：Google Gemini 3 Pro。
        *   **IDE**：AntiGravity（其中集成的Gemini S3免费额度足够使用）。
    *   **技术要点**：
        *   **字体**：英文推荐**英特尔**，中文推荐**思源黑体**。**重要提示**：需检查并要求AI将字体源从Google CDN切换为国内源，以确保离线或弱网环境可用。
        *   **前端技术栈**：
            *   **Tailwind CSS**：广泛使用的前端样式库，能让网页更美观。即使你不懂，AI也懂。
            *   **Vue 3**：对于页面复杂、每个页面都有独立动画的情况，强烈推荐使用Vue 3构建工程目录。好处是支持**热更新**，修改后页面自动刷新，提升效率。
    *   **提示词**：UP主提供了提示词供观众直接复制使用（需截屏保存）。

2.  **第二步：思考流程并工具化——设计“工具链”**
    *   **核心观点（暴论）**：没有工具链的Skill没有意义。
    *   **工具的核心作用**：**约束AI的随机性**和**提高效率**。
    *   **以PPT Generator为例的两个关键工具**：
        *   **封面模板生成器**：固定格式，精准控制生成，约束AI的天马行空。
        *   **带自动热更新的Web服务器**：实现“左边AI修改，右边屏幕立刻刷新”，极大提升验证效率。
    *   **总结**：永远别让AI在毫无约束的情况下生成复杂内容。

3.  **第三步：流程跑通后，用`Skill Creator`打包技能**
    *   **步骤一**：向`Skill Creator`阐述整个完成的流程。
    *   **步骤二**：让`Skill Creator`读取已做好的PPT模板，提取满意的设计细节（如字体、排版、金句排版偏好），写入`Skill.md`文件。
    *   **步骤三（懒人法/进阶）**：要求`Skill Creator`直接修改脚本，支持“抽卡”功能（如输入参数支持抽5次、10次）。

## 效果验证与成本
*   **本地模型验证**：UP主实测，即使使用 **GLM-4.7 Flash** 这个30B参数的“超级小模型”（内存足够可在CPU上运行），也能在本地完美运行这个Skill。
*   **最终效果**：实现**零成本**，利用超高速并发的本地小模型，进行**无限次自抽卡**，生成PPT。

## 总结核心要点
本视频通过演示用Claude Code和自定义Skill一键生成乔布斯风格PPT的案例，核心教授了一套将重复性脑力劳动**自动化**的通用方法论：首先用AI高质量完成一次任务并提炼模板，接着将核心流程工具化以约束AI、提升效率，最后用Skill打包成可复用、可参数化（如支持“抽卡”）的智能体。掌握此法则，不仅限于PPT，能开启一个高效、优雅的自动化工作新世界。
