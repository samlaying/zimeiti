# 05 笔记也可以 Agent

> [codexu](https://space.bilibili.com/283876696) | [BV1oUrGBYEvi](https://www.bilibili.com/video/BV1oUrGBYEvi) | 时长 1:36

## NodeGen Agent模式：AI辅助笔记写作

### 什么是Agent模式
- NodeGen从V0.2 3.0版本开始支持Agent模式，允许用户以类似Webcoding的体验，通过AI辅助完成笔记工作。
- 用户只需将想法告诉AI，AI会自动执行任务，节省手动操作时间。

### 如何使用Agent模式：完整实操步骤
1. **切换模式**：在NodeGen的对话工具中，将Chat模式切换成Agent模式。
2. **下达指令**：向AI下达具体任务，例如“创建一个文件夹并在其内部生成几篇关于Markdown语法的演示笔记”。
3. **AI执行任务**：AI会自动创建文件夹（例如“MacDone视力文件夹”）并生成相关笔记，用户需等待AI处理。
4. **手动确认生成**：AI完成每篇笔记后，会提示用户手动确认是否生成；确认后，笔记内容将按计划正确生成。
5. **修改内容**：如需对笔记进行修改（如补充表格内容并按年龄从小到大排序），可继续使用Agent模式下达指令，AI会自动处理并等待确认。

### 具体演示例子
- **创建笔记示例**：AI根据指令生成关于Markdown语法的演示笔记，文件夹自动创建，用户确认后笔记生成。
- **修改内容示例**：用户要求AI将笔记中的表格内容进行补充，并按年龄从小到大排序；AI处理后，用户确认即可实现修改。

### 好处与建议
- **节省时间**：通过Agent模式，用户无需手动编写或编辑笔记，AI自动完成核心任务，显著提高效率。
- **建议**：鼓励用户尝试使用NodeGen的Agent模式来辅助笔记工作，体验AI驱动的自动化写作。
- **支持开源**：该项目为公益开源，用户的STAR（星标支持）是对项目的最大鼓励。

### 总结核心要点
NodeGen的Agent模式通过AI自动化执行笔记创建和修改任务，用户只需下达指令并手动确认，即可高效完成笔记工作；这不仅节省时间，还提升了写作体验，适合追求提效的用户尝试。
