## 注册NVIDIA账户
### 步骤
1. 访问NVIDIA相关网站（具体网址未在字幕中明确，但需通过浏览器访问）。
2. 点击注册，输入账号名称。
3. 验证邮箱：收到验证码后输入确认。
4. 验证手机号：根据提示完成手机验证。

## 获取API Key
### 步骤
1. 登录NVIDIA账户后，在控制面板中找到生成API Key的选项。
2. 为API Key起一个名字（随意命名）。
3. 设置过期时间：选择“Never”（永远不过期），以确保长期可用。
4. 复制生成的API Key，保存备用。

## 安装OpenCode
### 步骤
1. 访问OpenCode官方网站（具体网址未提供，需自行搜索）。
2. 对于Windows用户，建议使用NPM安装：
   - 首先确保已安装Node.js环境（如未安装，需先下载并安装Node.js）。
   - 通过命令行使用NPM命令安装OpenCode。
3. 按照官网指引完成安装。

## 配置和使用OpenCode
### 设置API Key和模型
1. 打开OpenCode工具。
2. 在模型切换界面，首次使用时，按Ctrl+A键选择新模型。
3. 粘贴之前复制的NVIDIA API Key到指定输入框。
4. 选择模型：从提供的模型列表中挑选，如Kimi K2、MiniMax M2等。
   - 示例：默认模型如“pn名什么”（字幕中提到，但具体名称可能为笔误，建议根据实际界面选择）。
5. 测试使用：输入查询或任务，观察响应速度和质量。
