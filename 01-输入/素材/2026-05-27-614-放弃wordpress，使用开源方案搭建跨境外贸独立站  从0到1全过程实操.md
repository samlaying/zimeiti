# 放弃wordpress，使用开源方案搭建跨境外贸独立站 | 从0到1全过程实操

> [软件工程师Tim](https://space.bilibili.com/368778383) | [BV1JGChBZENo](https://www.bilibili.com/video/BV1JGChBZENo) | 时长 12:07

## 引言：放弃WordPress的原因
UP主Tim是程序员，在搭建跨境电商独立站时，比较了WordPress和开源方案。WordPress虽然强大流行，但过于臃肿，包含不需要的功能，拖慢网站速度，且完全掌握至少需要三个月时间。因此，他选择使用开源方案（基于Python后端和React前端）自己搭建网站，该网站结构简单，包含四个菜单和About页面。

## 搭建流程概述
整个搭建过程分为四步：准备环境、复制源码到服务器、配置网站、测试访问。这是一个从0到1的实操过程，适合有基础编程和服务器运维经验的人。

## 详细步骤

### 第一步：准备环境
需要准备以下环境和工具：
- **域名**：提前购买，例如Tim在腾讯云上购买的域名（如010.fk2.com）。
- **服务器**：使用Hostinger服务器，内存为2G，通过Secure CRT连接（本地Shell工具）。
- **Python环境**：已安装，用于后端运行。
- **Node环境**：用于前端，需安装Node.js和npm。
- **MySQL数据库**：用于存储数据。
- **Nginx**：用于反向代理和网站服务。
- **操作系统**：使用Ubuntu系统，安装软件可通过`apt install`命令（例如`apt install node`）。不同系统安装方法不同，建议在ChatGPT上搜索具体安装指南。

### 第二步：复制源码到服务器
- **源码结构**：开源项目分为后端（server文件夹）和前端（web文件夹），附带README说明书。
- **复制方法**：使用FlashFXP工具（文件传输工具），左侧为本地目录，右侧为远程服务器目录。选中文件夹后点击传输，将源码复制到服务器的`/var/webb2b`目录下。
- **操作示例**：Tim已提前传输完毕，远程目录中看到webb2b文件夹。

### 第三步：配置网站
配置过程涉及数据库、后端、前端和Nginx，参考源码中的README说明书。

#### 数据库设置
- **建库并恢复数据**：在服务器上执行建库语句，数据库名称可自定义（如web_b2b）。
  - 命令：`mysql -u root -p`连接数据库。
  - 执行建库语句：`CREATE DATABASE web_b2b;`。
  - 恢复数据库：使用`source`命令，例如`source web_b2b.sql;`。
  - 验证：执行`SHOW TABLES;`确认所有表已创建。

#### 后端配置与运行
- **修改配置文件**：编辑`server`文件夹下的`settings`文件。
  - 将`DEBUG`模式改为`False`（生产模式）。
  - 修改`HOST`为自己的域名（如010.fk2.com）。
  - 更新数据库名称和密码为自定义设置。
  - SMTP配置可根据需求调整（Tim未用）。
- **运行后端**：在服务器上进入`/var/webb2b/server`目录，运行后端命令（具体命令未在字幕中明确，但根据上下文是Python相关命令）。Tim示例中使用Linux命令运行。

#### 前端配置与运行
- **修改环境文件**：编辑`web`文件夹下的`env`文件，将域名改为自己的域名（如HTTPS://010.fk2.com）。
- **安装依赖**：在`web`文件夹下执行`npm install`安装前端依赖。
- **打包**：执行`npm run build`进行打包，时间约5分钟。
- **启动前端**：使用Linux命令启动前端服务（具体命令未明确，但类似后端）。

#### Nginx配置
- **创建配置文件**：在`/etc/nginx/conf.d`目录下新建配置文件（如020.conf）。
- **编辑配置**：将示例配置内容复制到文件中，修改域名为自己的域名，调整上传文件夹路径为远程服务器路径。
- **上传配置**：使用FlashFXP将配置文件粘贴到服务器对应目录。
- **重启Nginx**：执行`nginx -s reload`命令重启服务。

### 第四步：测试访问
完成所有配置后，通过域名访问网站，如输入010.fk2.com，应能正常打开跨境电商独立站。Tim确认部署成功，网站可访问。

## 总结
核心要点是：放弃臃肿的WordPress，采用开源Python+React方案搭建跨境电商独立站，通过四步实操（准备环境、复制源码、配置网站、测试访问）实现从0到1的部署。关键包括域名和服务器准备、源码传输、数据库和Nginx配置、前后端运行，整个过程强调自主可控和效率，适合有基础的程序员快速搭建高性能独立站。
