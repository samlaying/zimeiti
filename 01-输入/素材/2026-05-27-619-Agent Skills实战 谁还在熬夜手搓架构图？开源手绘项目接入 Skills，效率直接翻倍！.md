# Agent Skills实战 谁还在熬夜手搓架构图？开源手绘项目接入 Skills，效率直接翻倍！

## 项目概述
- 这是一个在Gateo平台上获得最近12万关注的开源项目，专注于帮助用户绘制图表，如流程图和架构图，并提供丰富的素材支持。
- 项目开人仅8天，已经收获1K的Stars（SAR可能指Stars），显示其受欢迎程度和快速成长。
- 手动绘制架构图已过时，现在可以通过集成"Excarager"和"Skills"工具来自动化和提效。

## 工具介绍
- **Skills**：类似于一个说明书或提示词机车，携带了要调用的工具和文件信息，方便用户通过自然语言指令操作。
- **Excarager**（或Excelager）：一个开源绘图工具，与Skills结合后，可以自动生成流程图和架构图，避免手动绘制。

## 实操步骤
### 安装步骤
1. **执行命令安装**：用户只需执行两个命令来安装相关工具（字幕中提到的"fgues"，可能指figures或绘图相关包）。
   - 第一步：在Cloud Code（可能是一个代码编辑器或工具）中贴入第一个安装命令，按一个按键确认，等待安装完成。
   - 第二步：同样安装第二个工具（可选，但推荐安装以防万一），过程类似。
2. **重启工具**：安装完成后，建议关闭并重新打开Cloud Code，以确保Skills被正确加载。
3. **手动安装替代**：如果需要，用户也可以通过手动方式设置Skills，因为Skills本质上是一个携带指令的说明书。

### 验证安装
- 使用"Polling"命令（或特定查询命令）检查Skills是否安装成功。在Cloud Code中执行后，应看到"Maini写第二个"等提示，确认Skills已就绪。

### 使用方法
1. **提示绘图**：输入自然语言指令，例如"使用Excelager画一张学生管理的架构图"。
2. **工具响应**：工具会自动处理，如果是第一次使用，会询问是否创建Excelager文件；用户确认后，工具生成相关文件（如"StudentExcelager"）。
3. **查看结果**：打开生成的文件（如从文件加载当前项目），选择创建的Excelager，流程图或架构图就会自动生成。
4. **优化建议**：确保题字词（提示词）描述足够清晰，以获得更精确和高质量的图表输出。

## 示例和优化
- **具体例子**：在演示中，UP主使用"学生管理架构图"作为示例，展示了如何通过指令快速生成图表。
- **数据和建议**：项目强调效率提升，避免熬夜手搓架构图；建议用户优化提示词，以充分利用Skills和Excarager的能力。

## 总结
核心要点：这个视频介绍了一个新兴开源项目，通过集成Skills和Excarager工具，用户可以利用自然语言指令自动绘制流程图和架构图，显著提高工作效率，告别手动绘图的繁琐过程。项目快速获得关注，展示了AI工具在开发中的实际应用，适合需要频繁绘制图表的开发者和设计师参考。
