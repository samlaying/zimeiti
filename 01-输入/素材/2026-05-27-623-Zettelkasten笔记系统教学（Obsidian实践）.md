# Zettelkasten笔记系统教学（Obsidian实践）

> [枸杞加水](https://space.bilibili.com/358065206) | [BV1vJ6GBbEv5](https://www.bilibili.com/video/BV1vJ6GBbEv5) | 时长 20:00

## 介绍Zettelkasten系统
Zettelkasten，也称为卡片笔记法或原子笔记法，是由德国社会学家尼克拉斯·卢曼在20世纪发明的笔记系统。卢曼利用此系统在一年内获得博士学位，并在30年间撰写了58本书，展现了极高的生产力。该系统旨在通过结构化笔记提升学习效率，避免无效笔记，使所有笔记都能发挥实际作用。

## 核心原则
### One Note One ID
每篇笔记只包含一个想法，笔记应原子化，分割为最小不可分割的单元。这便于在笔记之间建立连接，形成知识网络。
### 连接而非收集和分类
笔记的关键在于连接，而非简单收集或分类。创造力源于连接不同知识点，通过连接新旧知识加深记忆和巩固理解。在Obsidian中，可通过Graph View可视化知识网络。
### 做笔记制作者而非收集者
避免直接复制原文，应使用自己的话输出想法，运用费曼学习法：通过向他人讲解知识来加工和巩固内容。笔记库应被视为交流对象，每条笔记都是与未来的自己对话。

## 笔记类型
Zettelkasten系统包含三类笔记：
1. **临时笔记**：随时记录想法，类似草稿，不作为最终笔记。
2. **文献笔记**：阅读或输入时做的简略笔记，帮助思考，提取关键词或绘制导图。
3. **永久笔记（原子笔记）**：核心笔记，需详细撰写，像教给不懂该知识的人。这些笔记是自己输出的内容，确保原创性。

## 确保笔记被发现
为避免笔记被遗忘，需确保每条笔记都能在未来被发现。方法包括：
- **链接到Index（主页）**：主页是根笔记，所有笔记都应能通过链接回主页。主页类似地图，指引找到任何笔记。
- **建立链接链条**：笔记要么直接链接到主页，要么链接到链接到主页的笔记（例如，Library链接到主页，心理学笔记链接到Library）。
- **示例**：在Obsidian中，通过主页找到书籍如《当下的力量》，可通过两条路径：直接链接到主页的Book笔记，或通过Library→心理学板块链接。

## 卢曼的原始系统与现代实现
卢曼使用纸质卡片和编号系统：每张卡片有独特编号（如A1、A2），通过在笔记中写入编号来链接。当卡片盒装满时，使用新盒子（如C1、C2）继续编号。现代工具如Obsidian简化了此过程，通过双链功能轻松实现链接，效率远超传统方法。

## 实操步骤和例子
### 写作示例
1. 创建原子笔记，例如关于Zettelkasten的笔记：“One Note One ID”。
2. 在写作时，打开相关笔记，复制内容到新文章中，并取消链接。
3. 通过链接链条（如One Note One ID → Stop being a note taker → 费曼学习法）快速拼接文章。
4. 利用AI工具（如复制内容给AI）进行语言衔接和优化。
### 编程示例
1. 学习编程时，创建主题笔记如“编程”。
2. 为特定语言（如C++）创建笔记，并子笔记如“C++内存管理”。
3. 学习其他语言（如Rust）时，创建类似笔记，并链接相关笔记（如Rust内存管理链接到C++内存管理）。
4. 创建总结笔记如“不同语言的内存管理流派”，链接相关笔记并撰写比较。
### 读书示例
1. 阅读书籍（如《人类简史》）时，创建原子笔记如“快乐的来源”。
2. 链接到其他书籍笔记（如《当下的力量》的“佛教思想”笔记），通过链接发现知识碰撞，梳理关系并撰写分析。

## 适用领域和资源
Zettelkasten适用于所有领域（如文科、理科、工科），因为它基于大脑的知识组织方式：单独知识点通过连接形成网络。推荐资源：
- 书籍《How to Take Smart Notes》（中文名：如何聪明的做笔记），完整介绍Zettelkasten系统。
- UP主提供的示例笔记库：包含主页指引、日记模板、CSS美化代码、插件配置、项目管理和图书馆等示例，可通过B站动态获取。

## 总结核心要点
Zettelkasten系统通过原子化笔记和强调连接，将笔记转化为动态知识网络，提升学习效率和创造力。它鼓励主动输出而非被动收集，确保每条笔记都能被发现和利用。在Obsidian等工具中实践时，通过链接到主页和建立链条，实现高效知识管理，适用于各种领域，是提升个人生产力的强有力方法。
