# 自媒体内容系统

输入 → AI 自动处理 → 平台适配 → 输出 + 复盘

## 目录结构

| 目录 | 用途 |
|------|------|
| `01-输入/` | 所有外部内容的落脚点 |
| `02-处理/` | AI 分析、分类、标注、关联 |
| `03-分发/` | 各平台的规则和适配策略 |
| `04-输出/` | 终稿 + 发布 + 复盘 |
| `100-个人能力/` | 个人能力相关 |

## B站素材分类（01-输入/B站-整理素材/）

| 目录 | 类别 | 核心内容 | 对应目标 |
|------|------|----------|----------|
| `A-学工具练手感/` | A: 学工具·练手感 | 工具教程、编程开发、视频制作、自动化、设计、剪辑、知识管理 | AI实操 |
| `B-学产品备面试/` | B: 学产品·备面试 | 产品经理方法论、PRD、需求分析、UX、面试、求职、职业发展、商业思维 | AI产品经理 + 面试 |
| `C-学认知看趋势/` | C: 学认知·看趋势 | 模型评测、技术原理、架构解读、行业观点、深度思考、概念解析 | 认知提升 |

## 文件命名规范

```
YYYY-MM-DD_标题.md
```

## 工作流

1. 选题入库 → 放入对应分类文件夹
2. 脚本撰写 → 同目录下创建稿件
3. 完成后标记状态（frontmatter: status: draft/published）

详见 `_分类规则.md`
